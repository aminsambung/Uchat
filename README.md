# Uchat — Aplikasi Chatting Android

Aplikasi chat Android lengkap dengan fitur seperti WhatsApp + PIN ala BBM.
Dibangun dengan **Kotlin**, **Jetpack Compose**, dan **Firebase**.

## ✨ Fitur

- ✅ Registrasi dengan **PIN unik 8 karakter** (ala BBM) dan **Username** (ala Telegram)
- ✅ Login/Logout dengan email & password
- ✅ **Private Chat 1-on-1** (ruang terpisah per pasangan pengguna)
- ✅ Kirim teks dan **gambar**
- ✅ **Unread badge** (angka hijau)
- ✅ **Centang biru** (read receipt)
- ✅ **Hapus pesan** (untuk saya / untuk semua)
- ✅ Indikator **"sedang mengetik..."**
- ✅ **Status 24 jam** (teks, gambar, video)
- ✅ **Edit profil** (nama, tentang, foto)
- ✅ **Fitur Ping** ala BBM (getar + suara + notifikasi)
- ✅ 3 tab utama: Pesan, Pembaruan, Panggilan
- ✅ Halaman Pengaturan lengkap
- ✅ Dark mode khas WhatsApp

## 🛠️ Teknologi

- Kotlin
- Jetpack Compose (Material 3)
- Firebase Authentication
- Firebase Firestore
- Firebase Storage
- Firebase Cloud Messaging (FCM)
- Firebase Cloud Functions
- Media3 ExoPlayer (untuk video status)
- Coil (untuk load gambar)
